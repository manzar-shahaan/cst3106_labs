
# Yatzy Design System Documentation

This documentation provides an overview of the design system to be used for the Yatzy game project.

## **1. Color Palette**

- **Background Color:** `#0b0d10`
- **Board Colour:** `#4ba64f`
- **Board Bezel Colour:** `#9b624d`
- **Text Color:** `#e7eaee`

## **2. Typography**

- **Headings / Title:** `'Geist Pixel', sans-serif`
- **Body, Subheadings & Score Table:** `'Chakra Petch', sans-serif`

## **3. Design Rationale**

These colors and fonts reflect my understanding of Yatzy's roots and its cultural popularity in Scandinavia and the Nordics.

The typography pairs a pixel-style display font (Geist Pixel) with a squared sans-serif (Chakra Petch) to reinforce the retro arcade look; Chakra Petch handles body and table text.

## **4. Layout and flow**

Game begins with a splashscreen that shows the Yatzy title and a start button. Once the game is started, the layout shows the main player area with two player areas in the centre of the screen, along with the score table on the right side. There is a button for the player to roll the dice which displays 5 dice in the main player area, which are selectable(with the goal of creating any of the combinations from the table) every turn up to 3 rolls of the dice. The player with the higher score wins.
