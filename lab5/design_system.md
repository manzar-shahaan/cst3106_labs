
# Yatzy Design System Documentation

This documentation provides an overview of the design system to be used for the Yatzy game project.

## **1. Color Palette**

- **Background Color:** `#0b0d10`
- **Board Colour:** `#4ba64f`
- **Board Bezel Colour:** `#9b624d`
- **Text Color:** `#e7eaee`

## **2. Typography**

- **Headings / Title:** `'Geist Pixel', sans-serif`
- **Body, Subheadings & Score Table:** `'Chakra Petch', sans-serif`

## Design Rationale

These colors and fonts reflect my understanding of Yatzy's roots and its cultural popularity in Scandinavia and the Nordics.

The typography pairs a pixel-style display font (Geist Pixel) with a squared sans-serif (Chakra Petch) to reinforce the retro arcade look; Chakra Petch handles body and table text.
